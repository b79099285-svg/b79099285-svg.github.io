# Шрифты

В проекте используются два шрифта с открытой лицензией **SIL Open Font License 1.1**:

- **Manrope** — Copyright 2018 The Manrope Project Authors.
  Источник: https://github.com/sharanda/manrope
- **Unbounded** — Copyright 2022 The Unbounded Project Authors.
  Источник: https://fonts.google.com/specimen/Unbounded

Файлы `woff2` — это сабсеты (кириллица + латиница), собранные из Google Fonts.
Полный текст лицензии — в `OFL.txt` рядом с этим файлом.

Шрифты можно свободно использовать, встраивать и распространять вместе с сайтом.
Продавать их отдельно нельзя.
