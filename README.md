# FexingProject — сайт CS2-сервера

Статический сайт для сервера **FexingProject**: Mirage, 5×5, бесконечные раунды и привилегии без pay-to-win.

Сделан под бесплатный хостинг **GitHub Pages**. Без сборки, без базы данных, без оплаты. Достаточно загрузить папку в репозиторий и включить Pages.

---

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Главная: герой, сервер, подключение, карта, привилегии, правила, FAQ |
| `privileges.html` | Тарифы VIP / Premium / Fexing и таблица сравнения |
| `rules.html` | Полные правила, наказания и апелляции |
| `404.html` | Страница «Раунд не найден» для GitHub Pages |
| `js/config.js` | **Главный файл настроек**: IP, ссылки, цены |
| `js/main.js` | Копирование IP, переключатель цен, меню, анимации |
| `css/style.css` | Вся вёрстка и оформление |
| `css/fonts.css` | Подключение локальных шрифтов |
| `assets/` | Логотип, фон, схема Mirage, шрифты, OG-обложка |
| `tools/og.html` | Исходник обложки для соцсетей (не нужен на сайте) |

Шрифты лежат локально — сайт не зависит от Google Fonts и работает офлайн.

## 1. Что обязательно поменять

Открой `js/config.js` и замени заглушки:

```js
server: {
  ip: "fexingproject.ru:27015",   // ← IP:порт твоего сервера
  status: "online"                 // online | maintenance | offline
},
links: {
  discord: "https://discord.gg/...",     // ← твой Discord
  telegram: "https://t.me/...",          // ← твой Telegram
  steam: "https://steamcommunity.com/groups/...",
  buy: "https://discord.gg/..."          // ← куда ведёт «Оформить»
},
prices: {
  vip:     { month: 149, forever: 990 },
  premium: { month: 299, forever: 1990 },
  elite:   { month: 499, forever: 3490 }
}
```

После этого IP и цены обновятся на всех страницах автоматически.

> В HTML тоже прописан запасной IP `fexingproject.ru:27015` — он виден, только если у пользователя отключён JavaScript. Для полной чистоты замени его поиском по проекту на свой.

### Что ещё стоит проверить

- **Ссылки Discord / Telegram / Steam** — сейчас это заглушки, ведущие на несуществующие адреса.
- **Способы оплаты** — на странице привилегий указаны СБП и карта. Если у тебя иначе — поправь текст.
- **Правила и наказания** — подгони под свою администрацию.
- **Регион `RU`** — если сервер в другой стране, поменяй в карточке сервера и в `config.js`.
- **`assets/og-cover.png`** — обложка для Telegram/Discord. Можно пересобрать из `tools/og.html` или заменить своей картинкой 1200×630.
- **`og:image`** — после публикации замени относительный путь на абсолютный, иначе часть мессенджеров не покажет превью:
  `https://ТВОЙ-НИК.github.io/fexingproject/assets/og-cover.png`. То же самое стоит сделать для `og:url`, если добавишь его.

После публикации проверь: открывается ли сайт с телефона, копируется ли IP, работает ли переключатель «Месяц / Навсегда» и не ведут ли кнопки Discord в пустоту.

## 2. Локальный просмотр

Сайт статический: можно просто открыть `index.html` в браузере.

Но чтобы всё работало как на хостинге (шрифты, `fetch`, якоря), лучше поднять локальный сервер:

```bash
# из папки fexingproject
python -m http.server 8080
```

Открой `http://localhost:8080`.

## 3. Публикация на GitHub Pages — бесплатно

Нужен аккаунт GitHub. Репозиторий должен быть **публичным** (иначе бесплатный Pages не включится).

### Вариант А. Через сайт GitHub, без командной строки

1. Создай новый репозиторий, например `fexingproject`. Не добавляй README — он не нужен.
2. На странице пустого репозитория нажми **Add file → Upload files**.
3. Перетащи **содержимое** папки `fexingproject` (сами файлы и папки `css`, `js`, `assets`, а не внешнюю папку целиком). Важно, чтобы `index.html` лежал в корне репозитория.
4. Нажми **Commit changes**.
5. Открой **Settings → Pages**.
6. В блоке **Build and deployment**:
   - **Source**: `Deploy from a branch`;
   - **Branch**: `main`;
   - **Folder**: `/ (root)`;
   - нажми **Save**.
7. Через 1–2 минуты сайт будет доступен по адресу:

```
https://ТВОЙ-НИК.github.io/fexingproject/
```

Если назвать репозиторий `ТВОЙ-НИК.github.io`, сайт откроется по короткому адресу `https://ТВОЙ-НИК.github.io/`.

### Вариант Б. Через Git

```bash
cd fexingproject
git init
git add .
git commit -m "FexingProject site"
git branch -M main
git remote add origin https://github.com/ТВОЙ-НИК/fexingproject.git
git push -u origin main
```

Дальше — **Settings → Pages → Deploy from a branch → main / (root) → Save**.

### Обновление сайта

Просто загрузи изменённые файлы в репозиторий (или сделай `git push`). GitHub Pages пересоберёт сайт автоматически за 1–2 минуты.

## 4. Свой домен (по желанию)

1. Купи домен (например, `fexingproject.ru`) у любого регистратора.
2. В DNS добавь `CNAME`-запись на `ТВОЙ-НИК.github.io`.
3. В GitHub: **Settings → Pages → Custom domain** — впиши домен и сохрани.
4. Включи **Enforce HTTPS** (сертификат выдаётся автоматически).

Для домена без `www` может понадобиться `A`-записи на IP GitHub Pages — смотри актуальную инструкцию GitHub.

## 5. Ограничения бесплатного GitHub Pages

- Только статика: нет серверного кода, форм и базы данных.
- Публичный репозиторий.
- Мягкие лимиты: ~1 ГБ на сайт и ~100 ГБ трафика в месяц. Для лендинга сервера этого хватает с запасом.
- Нельзя использовать для коммерческого магазина с оплатой на самом GitHub — оплата у тебя всё равно через Discord/бота.

Если понадобится онлайн-статус сервера или автовыдача привилегий, понадобится отдельный маленький бэкенд (VPS или Cloudflare Worker). Текущая версия — чистый лендинг.

## 6. Технические детали

- Никаких фреймворков и сборки: HTML + CSS + ванильный JS.
- Все ссылки относительные — сайт работает и в корне домена, и в подпапке `/fexingproject/`.
- Адаптив: 1440, 1024, 768, 390 px.
- Доступность: `skip-link`, `aria-*`, `prefers-reduced-motion`, фокус-стили.
- Копирование IP: `navigator.clipboard` с fallback на `execCommand` (работает и на `file://`).
- Переключатель «Месяц / Навсегда» запоминается в `localStorage`.
- Цены и IP берутся из `js/config.js`; при отключённом JS показываются значения из HTML.
- `404.html` подхватывается GitHub Pages автоматически.
- Никаких изображений Valve: фон и схема Mirage нарисованы в SVG специально для проекта.
